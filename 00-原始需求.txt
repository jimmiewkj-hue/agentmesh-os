本项目旨在尽可能充分利用现有电脑上所有 Agent 的能力，同时节省 token 费用并达到最佳效果；具体而言，针对本地安装的 Trae 国内版/国际版、WorkBuddy、Qoder、ZCode、OpenCode 、deepseek harness等国内版Agent，功能一实现跨软件的无损信息同步，确保任务上下文、文件变更和对话产物在不同工具间连贯流转；功能二允许任选其中一个 Agent 作为主节点、其余 Agent 作为子节点，形成主从协同架构；功能三由用户手动指定主节点 Agent 并选择能力最强的大模型后，将这个主节点agent负责识别用户需求、任务拆分，分发任务、总结问题并给出解决办法，并在项目关键的设计、审核、验收等环节以最少的输入输出 token 产出最大效益，把高价值决策与低 token 消耗的控制权集中在主节点；功能四由子节点负责项目文件浏览、工具调用、联网查询、执行主节点分派的任务以及特别消耗 token 的子步骤，如大规模代码扫描、多文件检索、反复试错调试等，从而形成“主节点统筹高价值决策与低 token 消耗、子节点承担执行与高 token 消耗环节”的协同机制；功能五记忆同步，历史对话同步，项目路径同步等控制实现。这只是一个不成熟的想法，你作为专业的agent  loop superagent工程师，批判性的确定软件主旨，并详细进行需求描述。
