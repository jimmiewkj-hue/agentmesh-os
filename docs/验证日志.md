## 5. 失败与修复记录

| 问题 | 处理 |
| --- | --- |
| 验收门禁引入后，旧测试仍期待 `pending_merge` | 测试改为：运行完成 → `pending_acceptance` → 验收 → `pending_merge` → 合并 |
| 语义缓存测试中两个 objective 略有差异 | 使用意图 Jaccard 0.875 命中阈值 0.82，验证 exact cache miss + semantic cache hit |
| Web 模板字符串嵌套导致 `node --check` 失败 | 拆成 `benchRows/benchHtml` 普通字符串拼接，重新通过 |
| 新增 CLI 产品离线时仍显示能力 | 未找到可执行文件时关闭全部能力，避免虚构 |
| REA 自动发现误把 `Path("")`（即 `.`）当 REA 目录 | 改为只接受显式 `AGENTMESH_REA_HOME`、`ctx.rea_home`、`~/rea`、`C:/rea`、`D:/rea`，且必须存在 `.mcp.json` |
| 空 Git 仓库 `rev-parse` 返回字符串 `HEAD` 被当成 commit | `detect_repo` 仅在返回码 0 时取 branch/commit，`HEAD` 视为空 |
| 空项目无法创建 Worktree | 新创建/空目录初始化时生成初始 commit；已有用户内容的目录不自动提交 |
| 刷新模型时覆盖用户手填模型 | `replace_discovered_models` 只删除 `discovered/session/cli` 来源，保留 `user/registered` |
| 版本指纹被用户选配模型干扰 | 指纹只包含版本/适配器/能力/集成配置，不包含模型目录 |
