# Web 控制台的工作目录选择器（参照 DSH web 版）

- 版本：v1（2026-11-04）
- 关联代码：`agentloop_hub/control/fsbrowser.py`、`api/server.py`、`api/static/index.html`、`app.js`

---

## 0. 背景

Web 控制台第 1 步「项目目录」原来只有一个文本框，路径要手打。本项参照
DeepSeek Harness（DSH）的选择器实现，把「浏览本机目录 → 选中 → 回填」补齐。

## 1. DSH 是怎么做的（逆向 app.asar 实测）

在 `%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\app.asar` 中检索到两层实现：

**桌面壳（Electron）**：渲染进程经 `desktop.pick()` 调主进程原生对话框——

```js
const result = dialog.showOpenDialog(window, {
    properties: ["openDirectory", "createDirectory"] })
  .then(({ canceled, filePaths }) => canceled ? null : filePaths[0] ?? null);
```

**浏览器（web 版）**：`desktop === undefined` 时走 `ctx.uiWorkspace.pickDirectory()`，
背后是一个 **browse 能力**的 directoryPicker：

| 操作 | 签名 | 语义 |
| --- | --- | --- |
| `pick()` | `→ {ok, value \| error}` | 选一个目录（桌面壳才有原生对话框） |
| `list(path, signal)` | `→ 目录清单 + ancestry` | 列出某一层，**带回面包屑祖先链**，`AbortController` 可取消 |
| `createDirectory(path, name)` | `→ 新目录绝对路径` | 浏览器里直接新建文件夹 |

配套 UI 行为（React 侧）：路径输入框可直达、扫描进行中有 slow-scan 提示、
新一次导航会**作废**旧的在途请求（supersession）。

> 结论：浏览器拿不到绝对路径（`showDirectoryPicker()` 只给不透明句柄），
> 所以 web 版的正确形态是「服务端列目录 + 页面内浏览」，而不是调原生对话框。

## 2. AgentMesh 的实现

| 端点 | 说明 |
| --- | --- |
| `GET /api/fs/list?path=` | 列出某层：`entries[]`（目录优先、标记 hidden/size）、`ancestry[]`（根→当前，直接渲染面包屑）、`roots[]`（盘符）、`home/cwd`；**路径不存在返回 200 + `error` 字段**，选择器经常从失效路径打开，不能直接 400 |
| `POST /api/fs/mkdir` | 在父目录内新建一层；名称过滤 `\/:*?"<>|` 与 `.`/`..` |
| `GET /api/workspaces/recent` | 最近打开的项目（`~/.agentloop/recent-projects.json`，最多 12 条，去重、标记 exists） |
| `POST /api/workspace/init\|open` | 成功后自动记录进最近列表 |

**安全边界**：目录浏览会把本机文件系统暴露给页面，所以两个端点都要求请求方是
loopback（`_require_loopback` → `PermissionDeniedError`/403）。控制台默认绑
`127.0.0.1`，但即使用 `--host 0.0.0.0` 分享到局域网，浏览本机磁盘也不会跟着放开。

**前端**（`index.html` + `app.js`）：

- 「浏览…」按钮 → 页面内选择器弹窗：面包屑、盘符快捷入口、上一级/主目录、
  显示隐藏项开关、路径直达（回车）、双击进入/单击选中、新建文件夹、「选择此目录」；
- 弹窗内的加载沿用 DSH 的 supersession 语义：用请求序号作废在途响应，慢目录不会
  把旧结果盖在新结果上；
- 输入框下方渲染「最近打开」chips（已删除目录划线提示），单击回填。

## 3. 实测（2026-11-04）

### 3.1 自动化（`tests/test_fsbrowser.py`，25 例）

- 盘符真实存在；空路径返回 roots/home；
- 目录优先排序、hidden/size 标记、ancestry 根→当前；
- 目录不存在返回 `error=目录不存在`（不抛 4xx）、相对路径/文件路径拒绝；
- mkdir 成功、非法名（`..`、`a/b`、`a:b`…）拒绝、重名拒绝；
- 最近项目：去重置顶、上限 12、损坏 JSON 容忍；
- `is_loopback_address`：127.x/::1/localhost 通过，192.168.x 拒绝；
- HTTP：未打开工作区也能列目录；mkdir + 再列目录可见；`../escape` 返回 400。

## 4. 与 DSH 的差异（有意为之）

| 点 | DSH | AgentMesh | 原因 |
| --- | --- | --- | --- |
| 桌面原生对话框 | 有（Electron） | 无 | 服务端起在用户机器上时同样可用页面内浏览；Python 侧原生对话框（tkinter/COM）会阻塞 HTTP 线程且无头环境下挂死 |
| 取消在途列目录 | AbortController | 请求序号 supersession | 等效语义，且不依赖前端框架 |
| 新建文件夹 | 有 | 有 | 一致 |
| 最近工作区 | workspace.json | recent-projects.json | 一致 |
| 权限边界 | 桌面进程内 | 仅 loopback（403） | 本服务是 HTTP 服务，默认就绑 127.0.0.1，但要把边界说死 |
